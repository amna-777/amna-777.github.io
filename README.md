# Amna Shamsudeen — Portfolio
Responsive personal portfolio built with plain HTML, CSS and JavaScript. Your portrait is in `images/amna-photo.jpeg`.

## Preview
Open `index.html` in a browser.

## Publish using GitHub Pages
1. Sign in to https://github.com/amna-777.
2. Create a repository named `amna-777.github.io`.
3. Upload `index.html`, `style.css`, `script.js`, and the `images` folder to the repository root.
4. Open Settings → Pages.
5. Select deploy from the `main` branch and `/ (root)`, then save.
6. Once GitHub Pages deploys, visit https://amna-777.github.io.

Edit the text in `index.html` whenever you need to update your details or projects. Google Fonts load from the internet.
